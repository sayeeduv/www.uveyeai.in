# UNIQUE VISION EYE CLINIC & OPTICALS — Website

A responsive static website made for GitHub Pages. It uses HTML, CSS and vanilla JavaScript; no paid framework, server or database is required.

## Appointment form behaviour
GitHub Pages hosts static files and does not run a private booking database or server-side form handler. This site's appointment form validates the fields and opens WhatsApp (`+91 85558 08382`) with a pre-filled appointment request. The visitor must press **Send** in WhatsApp. The request is not confirmed until the clinic replies.

The form does not save patient data on the website. Avoid asking visitors to submit sensitive medical information in the note field.

## Publish free with GitHub Pages

1. Sign in or create a GitHub account at https://github.com/.
2. Create a **public** repository named `unique-vision-website`.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's root (not inside another folder).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then press **Save**.
7. Wait for GitHub Pages to publish. Your address will look like `https://YOUR-USERNAME.github.io/unique-vision-website/`.

GitHub may take a few minutes to publish the first time.
